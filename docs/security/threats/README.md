# Threat models

Each wave records changes to its attack surface and verifies its mitigations before closure. Foundation supply-chain and CI threats are specified in [W0 §6](../../../specs/waves/wave-00-foundation.md). Later threat models cover semantic event handling, the demo/public API, SVG parsing and the provider gateway.

A threat model records evidence for its actual implementation; an intended mitigation alone does not close a gate.
