# CI and supply-chain threat model

This Wave 0 delta covers dependencies, build output, CI workflows, environment values, and HTTP response policy. It is a design record for the foundation gate; hosted CI, dependency freshness, and release provenance remain separate evidence.

| Surface            | Threat                                                                            | Controls                                                                                                                                          | Residual evidence                                           |
| ------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| npm dependencies   | A compromised or vulnerable package executes during install or reaches the bundle | Frozen lockfile, `ignore-scripts`, minimum release age, SCA, SPDX allow-list, Dependabot/Renovate                                                 | CI audit and license reports                                |
| browser bundle     | A provider key or build canary is disclosed to an end user                        | Server-only environment boundary, explicit public-name rejection, static browser artifact scan, gitleaks                                          | `tests/unit/scripts/bundle-secret-scan.test.ts` and CI scan |
| server page output | A server-only value is incorrectly treated as browser code                        | Browser scan rooted at `.next/static`; `.next/server` is excluded from browser artifact discovery                                                 | Reachability and bundle-scan reports                        |
| HTTP response      | XSS, clickjacking, MIME confusion, insecure downgrade, or excess device access    | Per-request nonce CSP, `strict-dynamic`, `frame-ancestors 'none'`, `X-Frame-Options: DENY`, HSTS, `nosniff`, COOP, restrictive Permissions-Policy | Production Playwright header and CSP-violation test         |
| CI workflow        | Fork input gains write or secret access                                           | `pull_request` workflows, read-only token permissions, generated canary, pinned actions, concurrency cancellation                                 | Hosted workflow review                                      |
| license metadata   | A dependency introduces an incompatible license or missing metadata               | Explicit SPDX allow-list; unknown and non-allow-listed values fail                                                                                | `tests/unit/scripts/license-check.test.ts`                  |

The model does not claim that a local pass proves GitHub branch protection, CodeQL, hosted secret scanning, dependency policy freshness, or publication provenance. Those checks remain Wave 0/G0 evidence collected from the configured CI environment.
